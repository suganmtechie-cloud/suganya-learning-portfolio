Design principles built in

  • Start with performance: anchor the programme in a task learners need to do.
  • Model before practice: show what good performance looks like.
  • Make practice visible: include guided and independent application.
  • Assess evidence: check the task, not attendance alone.
  • Plan transfer: finish with a specific workplace action.
