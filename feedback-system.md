# Feedback system

## Daily pulse
1. What was most useful today?
2. What remains unclear?
3. How confident are you applying today's skill? (1–5)
4. What would make the next session more useful?

## Trainer observation
Participation and inclusion; practice vs. presentation time; recurring misconceptions; learners needing support; pacing and accessibility.

## Close the loop
Publish a short “You said — We changed” note:
- Feedback theme
- Change made
- Owner
- Version updated
- How we will check whether it helped

Use SBI (Situation—Behaviour—Impact), then agree one observable next step. Keep feedback specific, respectful and actionable.
