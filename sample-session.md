# Sample 90-minute session: Build and explain a simple REST API

**Audience:** early-career developers with basic programming knowledge  
**Outcome:** learners can explain request/response flow and implement/test one simple endpoint.

| Time | Activity | Evidence |
|---|---|---|
| 0–10 | Scenario hook, outcomes, diagnostic | Baseline |
| 10–25 | HTTP, routes, methods, status codes | Retrieval questions |
| 25–40 | Trainer think-aloud: build one endpoint | Annotated example |
| 40–60 | Guided lab: implement GET endpoint | Working endpoint |
| 60–72 | Pair challenge: add validation/error path | Peer review |
| 72–82 | Individual knowledge check | Quiz results |
| 82–88 | Explain design to non-technical stakeholder | Communication observation |
| 88–90 | Exit ticket and workplace commitment | Feedback |

This is a demonstration design, not a claim that this exact session has already been delivered.
