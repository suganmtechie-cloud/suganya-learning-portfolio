# Learning design approach

## The learning loop
1. **Discover** — business outcome, target roles, learner baseline, constraints and stakeholder expectations.
2. **Define** — observable learning objectives and success criteria.
3. **Design** — sequence concepts, examples, practice, feedback and assessment.
4. **Deliver** — facilitate actively; model thinking; adapt to learner signals.
5. **Demonstrate** — require practical performance, not just attendance.
6. **Improve** — analyse evidence, collect feedback and version the assets.

## Design principles
- Start with the work learners need to perform.
- Make objectives observable: build, explain, debug, compare, demonstrate.
- Use worked examples before independent practice.
- Make practice low-risk and feedback specific.
- Provide accessible, searchable, reusable learning materials.
- Connect technical outcomes with communication, collaboration and problem solving.

## Frameworks
ADDIE can structure the process; backward design defines evidence before activities; Kirkpatrick-style evaluation considers reaction, learning, behaviour and results. Adult learning principles emphasise relevance, autonomy, experience and immediate application.
